# 簡易待辦事項

一個單一 HTML 檔案的待辦事項小工具，不需要安裝任何開發環境、不需要伺服器，用瀏覽器打開就能用。頂部附帶一張即時天氣卡片，讓你在安排待辦事項時順便看一眼天氣。

## 解決什麼問題

臨時想記一下待辦事項，但不想為此註冊帳號、安裝 App，或依賴需要連網的雲端服務。這個工具就是一個檔案、開了就能用，資料留在自己的瀏覽器裡，適合單機、個人、輕量的待辦事項記錄。

## 主要功能

- 新增待辦事項
- 勾選標記完成 / 取消完成
- 刪除單一項目
- 一鍵清除所有已完成項目
- 顯示目前總數與已完成數量
- 重新整理或關掉瀏覽器後，資料仍保留（存在瀏覽器的 localStorage）
- 頂部顯示即時天氣：目前氣溫、天氣狀況、今日最高 / 最低溫、濕度
- 天氣地點可自動定位，也可手動搜尋任何城市（中英文皆可），會記住上次選的地點
- 天氣資料有 30 分鐘快取；離線時顯示上次成功取得的資料並標示

刻意不做的事：不分類、不設提醒、不排序、不支援多台裝置同步、沒有登入機制。資料只存在你目前這台電腦的這個瀏覽器裡，換一台電腦或換一個瀏覽器就看不到之前的紀錄。

天氣是唯一需要網路的功能：待辦事項本身完全離線可用，天氣卡片則會向 [Open-Meteo](https://open-meteo.com/) 取得資料（免費、免註冊、免 API key）。沒有網路時待辦事項照常運作，天氣卡片會顯示上次資料或提示無法連線。

## 安裝方法

不需要安裝。這是純前端的單一 HTML 檔案，沒有任何相依套件，也不需要 Node.js、npm 或任何伺服器。

1. 下載或複製本專案（只需要 [index.html](index.html) 這個檔案）。
2. 確認電腦上有一般瀏覽器（Chrome、Edge、Firefox 等）即可，不需要額外安裝任何東西。

## 使用方法

1. 用瀏覽器直接打開 [index.html](index.html) 這個檔案（在檔案總管中滑鼠雙擊即可，不需要啟動任何伺服器）。
2. 在最上方輸入框輸入待辦事項內容，按 `Enter` 鍵或點「新增」按鈕加入清單。
3. 想標記完成時，點選項目左邊的核取方塊；完成的項目文字會加上刪除線。
4. 想刪除某一項，點該項目右邊的「刪除」。
5. 想一次清掉所有已完成的項目，點右下角的「清除已完成」。
6. 天氣卡片第一次載入時，瀏覽器會詢問是否允許取得位置；允許就顯示所在地天氣，拒絕則預設顯示台北。
7. 想看其他城市，點天氣卡片上的「更換地點」，輸入城市名稱（例如「高雄」或「Tokyo」）後按 Enter 或「搜尋」；點「目前位置」可切回定位。
8. 點「重新整理」可立即抓取最新天氣。

## 輸入輸出範例

**輸入：** 在輸入框打「買晚餐食材」，按 Enter

**輸出：** 清單新增一行「☐ 買晚餐食材」，下方文字更新為「共 1 項，已完成 0 項」

**輸入：** 點擊「買晚餐食材」左邊的核取方塊

**輸出：** 該行變成「☑ ~~買晚餐食材~~」（文字加上刪除線），下方文字更新為「共 1 項，已完成 1 項」

**輸入：** 點擊「買晚餐食材」右邊的「刪除」

**輸出：** 「買晚餐食材」這一行從清單消失，下方文字更新為「共 0 項，已完成 0 項」；若清單變空，畫面會顯示「目前沒有待辦事項」

**輸入：** 清單中有 2 項已完成、1 項未完成時，點擊「清除已完成」

**輸出：** 2 個已完成項目一併從清單消失，只留下未完成的 1 項，下方文字更新為「共 1 項，已完成 0 項」

**輸入：** 點「更換地點」，輸入「Tokyo」，按 Enter

**輸出：** 天氣卡片切換為「🌧️ 22° 中雨 東京，東京都，日本」，下方顯示「最高 22° 最低 20° 濕度 95%」與「更新於 10:36」（數值依當時實際天氣而異）

## 技術說明

純前端，單一 `index.html` 檔案，內含 HTML / CSS / JavaScript，使用瀏覽器內建的 `localStorage` 儲存資料，沒有任何外部套件或依賴。

天氣功能使用 [Open-Meteo](https://open-meteo.com/) 的兩個公開端點：地理編碼 API（城市名稱轉經緯度）與預報 API（目前天氣與當日高低溫），皆以瀏覽器內建的 `fetch` 直接呼叫，不需金鑰。天氣代碼採用 WMO 標準，於程式內對應成中文描述與圖示。所選地點與最近一次天氣結果同樣存於 `localStorage`。
