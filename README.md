# 簡易待辦事項

一個單一 HTML 檔案的待辦事項小工具，不需要安裝任何開發環境、不需要伺服器，用瀏覽器打開就能用。

## 解決什麼問題

臨時想記一下待辦事項，但不想為此註冊帳號、安裝 App，或依賴需要連網的雲端服務。這個工具就是一個檔案、開了就能用，資料留在自己的瀏覽器裡，適合單機、個人、輕量的待辦事項記錄。

## 主要功能

- 新增待辦事項
- 勾選標記完成 / 取消完成
- 刪除單一項目
- 一鍵清除所有已完成項目
- 顯示目前總數與已完成數量
- 可選填到期時間，到期前 5 分鐘自動提醒（頁面內彈出提示，若已允許則同時發送瀏覽器系統通知）
- 即將到期與已到期的項目會以不同顏色標示
- 重新整理或關掉瀏覽器後，資料仍保留（存在瀏覽器的 localStorage）

刻意不做的事：不分類、不排序、不支援多台裝置同步、沒有登入機制。提醒只在頁面開著的時候運作，頁面關閉後不會提醒。資料只存在你目前這台電腦的這個瀏覽器裡，換一台電腦或換一個瀏覽器就看不到之前的紀錄。

## 安裝方法

不需要安裝。這是純前端的單一 HTML 檔案，沒有任何相依套件，也不需要 Node.js、npm 或任何伺服器。

1. 下載或複製本專案（只需要 [index.html](index.html) 這個檔案）。
2. 確認電腦上有一般瀏覽器（Chrome、Edge、Firefox 等）即可，不需要額外安裝任何東西。

## 使用方法

1. 用瀏覽器直接打開 [index.html](index.html) 這個檔案（在檔案總管中滑鼠雙擊即可，不需要啟動任何伺服器）。
2. 在最上方輸入框輸入待辦事項內容，按 `Enter` 鍵或點「新增」按鈕加入清單。
3. 若需要提醒，先在旁邊的日期時間欄位選好到期時間再新增；不選則沒有到期時間。
4. 第一次新增有到期時間的項目時，瀏覽器會詢問是否允許通知。允許後，提醒會同時以系統通知發送；不允許也沒關係，頁面右下角仍會彈出提示。
5. 想標記完成時，點選項目左邊的核取方塊；完成的項目文字會加上刪除線，且不再提醒。
6. 想刪除某一項，點該項目右邊的「刪除」。
7. 想一次清掉所有已完成的項目，點右下角的「清除已完成」。

提醒機制：頁面每 15 秒檢查一次，未完成且到期時間在 5 分鐘內的項目會提醒一次；若新增時到期時間已在 5 分鐘內或已過期，會立刻提醒。每個項目只提醒一次。

## 輸入輸出範例

**輸入：** 在輸入框打「買晚餐食材」，按 Enter

**輸出：** 清單新增一行「☐ 買晚餐食材」，下方文字更新為「共 1 項，已完成 0 項」

**輸入：** 點擊「買晚餐食材」左邊的核取方塊

**輸出：** 該行變成「☑ ~~買晚餐食材~~」（文字加上刪除線），下方文字更新為「共 1 項，已完成 1 項」

**輸入：** 點擊「買晚餐食材」右邊的「刪除」

**輸出：** 「買晚餐食材」這一行從清單消失，下方文字更新為「共 0 項，已完成 0 項」；若清單變空，畫面會顯示「目前沒有待辦事項」

**輸入：** 清單中有 2 項已完成、1 項未完成時，點擊「清除已完成」

**輸出：** 2 個已完成項目一併從清單消失，只留下未完成的 1 項，下方文字更新為「共 1 項，已完成 0 項」

**輸入：** 輸入「開會」，到期時間選 14:30，按 Enter

**輸出：** 清單新增「☐ 開會」，下方顯示「到期：09/16 14:30」。到了 14:25，該行到期文字變成橘色並顯示「（剩 5 分鐘）」，右下角彈出「「開會」將在 5 分鐘後到期（09/16 14:30）」的提示；若已允許通知，同時收到系統通知。過了 14:30 仍未勾選完成，到期文字變成紅色並顯示「（已到期）」

## 技術說明

純前端，單一 `index.html` 檔案，內含 HTML / CSS / JavaScript，使用瀏覽器內建的 `localStorage` 儲存資料，沒有任何外部套件或依賴。
